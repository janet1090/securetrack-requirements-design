# SecureTrack: Laboratory Equipment Tracking

SecureTrack is a proposed system for improving laboratory access control and tracking equipment movement. This was a COMP225 Software Engineering Methodologies group project at Centennial College.

## Proposed Features

- Role-based user authentication and laboratory access
- Equipment registration and RFID-based identification
- Equipment movement requests and approvals
- Alerts for unauthorized movement
- Audit logs and an administrative dashboard

## Project Materials

This repository contains the project’s Software Requirements Specification (SRS) and presentation, which document the requirements and system design.

## My Contribution

I proposed the SecureTrack idea and project topic. The requirements and design materials were developed as a group.

## Project Status

This repository documents a proposed system. It does not contain a built or deployed application.
